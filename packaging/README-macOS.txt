MetroFuse - Metroid Fusion, native for macOS

1. Drag MetroFuse into the Applications folder.
2. Open MetroFuse. The first time, macOS may say it is from an unidentified developer:
   right-click (or Control-click) MetroFuse, choose Open, then Open again.
3. Click "Choose ROM..." and pick your own dump of Metroid Fusion (USA).
   MetroFuse checks the file and remembers where it is. It never copies or uploads it.
4. Press Play. "Create Shortcut" adds a launcher that starts the game directly.

Settings and saves are kept in:
  ~/Library/Application Support/MetroFuse/MetroFuse/
